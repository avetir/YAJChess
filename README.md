## About This Project

This is a personal practice project where I’m building a chess engine in Java (and potentially more in the future, but for now I’m limiting myself to this).
I started it deliberately as a **solo effort** — to refresh my Java and software engineering skills, experiment with design ideas, and enjoy the process of building something from scratch.

If you’re curious, feel free to look around 🙂  
Comments, feedback, design discussion, and code review notes are very welcome.

Please keep in mind:
- I’m intentionally implementing everything myself
- I’m not accepting external code contributions or pull requests
- GitHub Issues are used for my own planning and progress tracking, not for claiming tasks

If you have thoughts or suggestions — I’d be glad to hear them in comments or discussions.
